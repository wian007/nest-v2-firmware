Captured 2026-10-26 via tools/omap-usbboot (GET_ID 0xF0030003) while the device
was in USB peripheral boot (0451:d00e). Proves the DFU/USB-boot route works and
that we can talk to the mask-ROM without sudo (NixOS uaccess udev rule).

Device type: GP (General Purpose) — confirmed independently by x-loader string
"TI OMAP SPL With GP CH". GP => ROM accepts unsigned images over USB boot.
(The helper's "device-type=TST" label is a parse heuristic artifact: 0x01 is a
subblock id, not the device type.)

Exact SoC marketing variant (AM3703 vs DM3730) is best read later from
CONTROL_IDCODE once we can run code; OMAP3 GP is sufficient for bring-up.

CONTROL_IDCODE (0x4830A204) = 0x2B89102F

     (DM3730 vs AM3703 differ only by SGX/DSP presence; same omap3 BSP base.)

Notes:
- /tmp is mounted noexec; run pushed binaries from /media/scratch (jffs2, exec ok).
- dropbear has no sftp-server: push files with `ssh root@host "cat > file"`, not scp.
- Device suspends to RAM via the userspace daemon `nlsleepd` (echo mem >
