lang.name=English
title=J49 installer
subtitle=Our own software on a Nest Learning Thermostat (2nd generation), from the browser
language=Language

nobrowser=This browser cannot reach USB devices. Use Chrome or Edge on a computer (Windows, Linux, macOS or ChromeOS), or Chrome on an Android phone.
insecure=The page must be opened over https or from localhost; otherwise the browser does not allow USB.

warn.title=Before you start
warn.1=This replaces the firmware of the thermostat. It then no longer works with the Nest or Google Home apps.
warn.2=It switches real heating and has no warranty. Read the disclaimer of the project first.
warn.3=Only the 2nd generation Nest Learning Thermostat (board J49, Display-2.x) is supported. On any other model this will fail or do damage.
warn.4=Make the backup. Without it there is no way back to the stock firmware.
warn.agree=I have read this and the disclaimer, and this is my own thermostat
windows=On Windows the first step needs the WinUSB driver once: start Zadig, choose "Options > List All Devices" while the thermostat is in its boot mode (step 2), select "OMAP3630" (USB ID 0451 D00E) and install WinUSB. Do the same later for "USB download gadget" (0451 DF10).

rom.title=2. Start the thermostat in its boot mode
rom.1=Take the thermostat off the wall and connect it to this computer with a USB cable that carries data.
rom.2=Click "Connect". A list opens; leave it open.
rom.3=Hold the ring pressed for 10 to 15 seconds, until the screen goes dark and the thermostat restarts. Keep it pressed.
rom.4=When "OMAP3630" appears in the list, select it and click "Connect" there. You can let go of the ring.
rom.button=Connect
rom.sending=Sending the loaders
rom.done=The thermostat starts the service kernel. Its screen shows text.

svc.title=3. Connect to the service
svc.1=Click "Connect to the service". A list opens; leave it open. A few seconds after the start "Gadget Serial" appears in it: select it and click "Connect" there.
svc.button=Connect to the service
svc.waiting=Waiting for the service to answer
svc.found=Connected. The thermostat has {n} partitions, {mb} MB.

backup.title=4. Backup
backup.1=The whole flash memory is read into one file on this computer. This takes a few minutes. Keep the file: it is the only way back.
backup.button=Choose where to save and start

uboot.title=5. Write the boot loader
uboot.1=Our U-Boot goes into both boot loader partitions, and the partition for the system is erased. From here on the thermostat no longer starts the stock firmware.
uboot.button=Write the boot loader
uboot.writing=Writing {name}
uboot.done=Written and read back. The thermostat restarts into our U-Boot.

dfu.title=6. Install the system
dfu.1=The screen is dark now: that is normal. Click the button and choose "USB download gadget" in the list. The page sends the kernel.
dfu.button=Connect and install

dfu.sending=Sending {name}
dfu.sent=Sent. The thermostat restarts and starts the new kernel; after about ten seconds its screen shows "J49 INSTALLER" again.
sys.title=7. Write the system
sys.1=The thermostat restarts and is then a USB serial port again. Wait for the button, click it and choose "Gadget Serial". The page then sends the root file system; the thermostat writes it to its flash memory and reads every block back.
sys.soon=The thermostat is restarting. You can go on in {n} seconds.
sys.button=Connect and write the system
sys.writing=Writing the root file system
sys.done=Written and read back. The thermostat restarts and starts the J49 software by itself.
panel.system=SYSTEM

restore.check=Checking the backup file
restore.button=Write the backup back
restore.writing=Writing {name}
restore.done=The backup is back. The thermostat restarts into the stock firmware.
restore.other=This backup has other partitions than this thermostat. It is not written.

done.backup=The backup is made. Nothing on the thermostat was changed. Take it off USB and hold the ring 10 seconds to restart it.
done.restore=The thermostat is back on the stock firmware.
